# Tiffany Stevenson | Portfolio website

A complete, responsive static HTML/CSS/JavaScript portfolio. No frameworks, subscriptions, or build process required.

## View locally
Open `index.html` in a web browser. Click each project card for its full case study.

## Publish for free
### Netlify Drop (easiest)
1. Unzip this folder.
2. Go to https://app.netlify.com/drop and sign up or sign in.
3. Drag the **tiffany_portfolio_site** folder onto the drop zone.
4. Your site will receive a free Netlify subdomain. You can rename it in site settings.

### GitHub Pages
1. Create a new GitHub repository.
2. Upload all files inside this folder, keeping `projects/` and `assets/`.
3. In repository Settings > Pages, set deploy source to the `main` branch, root directory.
4. GitHub Pages will show your website URL once it deploys.

## Personalise before sharing publicly
- Replace the stylised project illustrations with imagery you have permission to publish.
- Check the phone/email and CV in `assets/Tiffany_Stevenson_CV.pdf`.
- Check all work descriptions and project statuses for accuracy.
- The B2B portal is marked "In development", not launched.
- Analytics growth figures reference the two reporting periods and are not claimed as caused solely by the redesign.
- Optionally add your verified LinkedIn URL in the navigation or contact section.
- A Google Fonts request is used when online; system Arial fallback works offline.
- No analytics tracking or third-party JavaScript libraries are included.

## Files
